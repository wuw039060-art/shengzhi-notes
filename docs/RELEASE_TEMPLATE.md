# Release 模板

发布 GitHub Release 时可以复制这份内容。

## 声织笔记 vX.Y.Z

把音视频转成适合 Obsidian 的 Markdown 知识笔记。

### 本版内容

- Windows 安装包内置 FFmpeg 和 FFprobe
- 多文件任务队列
- 拖动排序、右键移除
- 任务按队列顺序逐个处理，避免接口并发超时
- 支持 70+ 种常见音视频格式，并自动检测音轨
- ASR 与文本排版模型设置
- 内置 Markdown 排版模板：
  - 演讲稿
  - 播客
  - 发布会
  - 会议
  - 课程笔记
  - 访谈
  - 直播复盘
- Markdown 预览后保存
- 长 Markdown 在预览区内独立滚动

### 适合谁

- 构建个人知识库的 Obsidian 用户
- 把播客和直播沉淀成内容资产的创作者
- 把课程变成结构化学习笔记的学生
- 归档访谈和音视频资料的研究者
- 把会议和发布会变成可搜索记录的团队

### 下载

在 Release assets 中下载 Windows 安装包：

```text
声织笔记 Setup X.Y.Z.exe
```

### 使用方式

1. 安装应用。
2. 打开连接设置。
3. 填写 ASR API Key。
4. 填写文本排版模型 API Key。
5. 拖入音视频文件并处理队列。

### 说明

- 安装包已内置 FFmpeg。
- 不需要本地 AI 模型。
- API 调用费用取决于你配置的供应商。
- 长音频会按 ASR 模型上下文限制自动切片。
