## 一句话定位

声织笔记把音频和视频转成适合 Obsidian 的 Markdown 知识笔记。

## 短介绍

声织笔记是一款本地优先的 Windows 桌面应用，面向正在构建个人知识库、第二大脑和数字资产库的人。拖入录音、播客、课程、直播、会议或访谈，接入自己的 ASR 和文本排版模型 API，即可导出适合保存进 Obsidian 的结构化 Markdown 文档。

## 长介绍

很多高价值信息都困在媒体文件里：会议、播客、直播、课程、访谈、语音备忘录、发布会。这些内容很难搜索、很难引用，也很难复用。

声织笔记把它们转成 Markdown。它使用本地 FFmpeg 做媒体转换，用你自己的 ASR API 做语音识别，再调用文本排版模型，把原始文字稿整理成结构化笔记。结果可以直接保存进 Obsidian 或任何文件夹式知识库。

它适合创作者、学生、研究者、创业者和知识工作者，用来把被动媒体变成长期可用的数字资产。

## 拿 Star 的关键点

- GitHub 描述里一定要出现 `Obsidian`、`Markdown`、`个人知识库`。
- README 首屏要放截图或 GIF。
- Release 里直接放 Windows 安装包。
- 强调安装包内置 FFmpeg，普通用户不用配置本地环境。
- 不要夸大“AI 自动理解一切”，要说清楚它连接用户自己的 ASR 和文本模型 API。
